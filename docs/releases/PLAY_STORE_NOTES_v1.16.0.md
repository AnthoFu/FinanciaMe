# Play Store Notes - v1.16.0

¡Una interfaz más moderna y fluida para tus finanzas! 🚀

En esta versión 1.16.0:

• 🔔 **Notificaciones Inteligentes:** Nuevo sistema de avisos (Toasts) global. Los errores y confirmaciones ahora aparecen de forma elegante y no intrusiva.
• 🎨 **Confirmaciones Modernas:** Hemos reemplazado los aburridos cuadros de texto del sistema por modales personalizados que respetan tu tema claro u oscuro.
• 🛡️ **Validación Mejorada:** Las alertas de errores en formularios ahora aparecen en la parte superior para que nunca pierdas de vista lo que estás haciendo.
• ⏱️ **Selector de Hora Renovado:** Configura tus recordatorios de gastos fijos con un nuevo selector horizontal mucho más rápido e intuitivo.
• 🧹 **Limpieza Visual:** Optimizamos los iconos y eliminamos avisos nativos molestos para una experiencia 100% personalizada.

¡FinanciaMe sigue evolucionando para ofrecerte la mejor experiencia financiera local! 💎
